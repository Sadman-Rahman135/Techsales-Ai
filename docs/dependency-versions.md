# Dependency versions

Installed, locked and tested on **2026-10-18** (blueprint §0, §5). Sources: PyPI, the npm registry, Docker Hub, nodejs.org.

**Pinning policy:** exact pins only. Each pin is the newest release that was **at least 7 days old** when chosen.
Brand-new releases carry the most risk of regressions and compromised packages, so we wait out a week.
Upgrades happen deliberately: change the pin, regenerate the lock, run all checks.
