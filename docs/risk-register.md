# Risk register (blueprint §17)

The ten risks of plan §17, with what was planned, what is built, the test that proves it, and what is still
open. Status: **✓** the planned mitigation is built and tested · **Partly** some of it is P1 ·
numbers are from the offline substitute models (docs/demos/12-evaluation.md, 14-15-repository-release.md).
Security threats are in [threat-model.md](threat-model.md). `tests/unit/test_repository.py` checks that every
test named here exists. Review this page with each release.
