# Feature demos

Every feature needs a screenshot or short recording here (blueprint §0), plus automated and manual tests.

- Name files `<plan-section>-<feature>.<png|webm|gif>`, e.g. `10.1-chat-citations.png`.
- Use only fictional TechCare demo data. No real secrets, tokens, emails, or customer data may be visible.
- Keep recordings short (under 30 s) and link them from the PR that delivered the feature.
- End-to-end demos from §12.5 and the final 3–5 minute video (§18) go in `docs/demos/e2e/`.
