(`/assistant`, `/assistant/[id]`), the document center's detail page (`/admin/documents/[id]`) with the list's remaining

(brand/category/type filters, ticket creation) are not shown anywhere (no teasers). Models are the offline fakes (§5.1),
so answer *wording* is extractive; the screens are what is under test.

## Design checklist (design-system/MASTER.md §11)

| Item | Result |
| --- | --- |
| Light and dark checked separately | ✓ Both on every new screen (screenshots in both themes); colors only through tokens, no raw hex in components |
| Status = icon + text | ✓ Evidence lines (BadgeCheck / SearchX / Info / TriangleAlert / Hourglass), Employee only (Lock), version and chunk states, KPI changes (arrow + sign + text), pass/missing in diagnostics |
| Keyboard | ✓ Skip link, Enter sends / Shift+Enter newline, tabs move with arrow keys (WAI-ARIA tabs), Esc closes the source panel and dialogs, focus returns to the chip |
| Screen reader | ✓ `role="log"` with `aria-live="off"` plus one polite announcement per finished answer; labelled icon buttons; dialogs named by their action; tables have captions |
| Touch targets ≥ 44 px | ✓ Buttons, chips and nav items use `min-h-11`; citation markers inside text are smaller but duplicate the 44 px chips below |
| Widths | ✓ 375 / 768 / 1024 / 1440 checked with a script on every new route; no horizontal scroll |
| Reduced motion | ✓ Global rule from §5 disables animation (typing dots, spinners, pulse) |
| Loading / empty / error / no-permission | ✓ Skeletons per page, "No questions in this period.", error boundary with reference, "Managers and admins only", "For TechCare staff" |
| No emoji, lucide only | ✓ |
| Charts (§10) | ✓ `--mark-pass` + hatched `--mark-target` (no new color, so no new palette to validate), series color never mixed with status colors, table view for every chart, 1 px solid gridlines, bars ≤ 24 px |

## Found and fixed while building

- Chrome refused to show PDFs inside the source panel: the file route's CSP `sandbox` blocks its PDF viewer in a frame.
  The BFF drops `sandbox` for `application/pdf` only (ADR-020); text stays sandboxed.
- History citations lacked the section name a live answer has; the conversation API now returns it.
- A rate-limited question showed "Something went wrong". It now shows "Please wait a moment" with the countdown.
- The publish refusal showed an internal message ("expected 1 chunks; Postgres has 1, Chroma has 0"); it now says what to
  do. "1 chunks" is now "1 chunk".
- The login form said "Work email", but customers sign in too.
