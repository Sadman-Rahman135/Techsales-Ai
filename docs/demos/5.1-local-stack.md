## Issues found and fixed during testing
- Port 5432 was taken by a locally installed PostgreSQL → the compose stack uses host port 55432.
- `localhost` cost ~2 s per connection on Windows (IPv6 tried first) → configs use `127.0.0.1`.
- A new httpx client per request cost ~200 ms → one shared client (2 ms).
